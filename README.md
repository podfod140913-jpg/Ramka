# Рамка

Сайт, который превращает ваш FACEIT API в оверлей для OBS. Зависимостей нет, нужен только Node.js 18+.

## Запуск у себя

    node server.js

Откройте http://localhost:3000, зарегистрируйтесь, в карточке FACEIT вставьте API-ключ
(developers.faceit.com → Create App → Server-side API key), введите ник и нажмите «Сохранить».
Ссылку из поля внизу вставьте в OBS как Browser Source (размер 600×120).

## Чтобы работало для стрима и для других людей

Выложите проект на хостинг (Render, Railway, Fly.io или свой VPS). Команда запуска: `node server.js`.
Задайте постоянную папку для данных через переменную DATA_DIR, иначе аккаунты сотрутся при перезапуске.

## Как устроено

- пароли хранятся как scrypt-хэш, вход по cookie-сессии (HttpOnly)
- FACEIT-ключ лежит только на сервере и не отправляется в браузер
- сервер сам опрашивает FACEIT и кэширует ответ на 30 секунд
- /o/<токен> отдаёт страницу оверлея с прозрачным фоном, она обновляется раз в 30 секунд
